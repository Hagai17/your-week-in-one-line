A tiny Python program that writes one line to `/output/entry.txt`: 99 characters summing up a week in which I taught my dad emojis and he now ends every text with the dynamite one, even about grandma. The line was picked by drafting twelve candidates and duelling them pairwise in both orders on the bounty judge's own criteria — sums up the entrant's own week, lands a real joke rather than stating a feeling, holds one concrete detail that could only be that week, spends every word well, and feels fresh rather than templated — then duelling the champion against a sample of live field entries. The drafts, the field sample and the duel record are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
